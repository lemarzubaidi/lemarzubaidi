### 🚀 Featured Projects

#### 🏦 [Banking System](https://github.com/lemarzubaidi/Bank-Project) — C++
A console banking system built with clean architecture principles.
- Client management and transactions: deposit, withdraw, transfer
- User authentication with account lockout after failed attempts
- Role-based access control using bitwise permissions
- File-based storage and login logging
- Each screen is a separate class, fully decoupled from business logic

#### ❤️ [Heart Disease Prediction](https://github.com/lemarzubaidi/python-ML) — Python · ML
A classification model that predicts heart disease from patient clinical data.
- Exploratory analysis: target distribution and correlation heatmap
- Logistic Regression model with an 80/20 train-test split
- Evaluated with accuracy, precision, recall, F1-score and confusion matrix (~84% accuracy)

#### 🧱 [SOLID Principles](https://github.com/lemarzubaidi/SOLID-Principles) — C#
Practical examples of the five SOLID principles and the Dependency Injection pattern, each showing a violating design next to the corrected one.
